# Android 原始客户端采集

适用于 MuMu Android 12 x86_64 中的官方 `com.lori.app` APK。采集只读取运行时数据；产物保存在项目内，会话凭据和原始流量不对外分享。

## 地图

1. 让角色停留在目标地图，不切图、不退出。
2. 运行 `powershell -ExecutionPolicy Bypass -File .\export-maps.ps1`。
3. 核对 `maps-local/<map-id>/map-<map-id>.json`、`map-<map-id>.png`和 `render-report.json`。`capture-report.json` 的当前地图必须是 `static_rendered`。

`export-maps.ps1` 复用 `read_map_object.py`。ART 堆快照非原子，入口会在当前地图首次失败时重试一次。不为单张地图新建导出脚本。

## 请求与响应

1. 在需要复现的操作之前运行：

   `C:/Users/Administrator/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe capture_protocol.py`

2. 执行一次最小用户操作，然后按 Enter 停止。产物位于 `captures/android-protocol/session-*/`：
   - `traffic.pcap`：官方服务器 `121.46.20.253:10000` 的原始双向 TCP 流量。
   - `messages.jsonl`：仅在 `--decoded` 成功附加时包含方向、消息编号、长度、SHA-256 和二进制文件名。
   - `*-request-*.bin` / `*-response-*.bin`：仅在明文钩子成功时生成。

采集器复用 `capture_map_memory.py` 中的 MuMu ADB 配置，使用项目内 `analysis-tools/frida-python` 和模拟器内 `/data/local/tmp/world-frida-server`。运行 `capture_protocol.py --self-check` 验证本地落盘格式。

2026-09-05 实测：官方 APK 可正常产生 PCAP，但运行中的主进程拒绝 Frida 附加，启动期注入会在 ART 就绪前结束进程。因此 `--decoded` 不是已验收能力；默认只采集 PCAP，再按下节用原始 DEX/Smali 推断明文结构。

已验收样本 `captures/android-protocol/session-20260905-231323/traffic.pcap`：44 包，双向端点为 `10.0.2.15:45398` 与 `121.46.20.253:10000`，内含世界村地图移动期间的上下行数据。

## NPC 列表与对话

1. 让角色重新进入目标地图，等待 NPC 全部显示；不要切图或退出。
2. 运行：

   `C:/Users/Administrator/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe read_npc_objects.py --output captures/android-protocol/<session>/npc-runtime.json`

3. 核对输出的 `mapId`、`npcCount`、名称、格坐标、`dialogue` 主对话、交互参数数组和 `missions` 任务对话。`dialogue` 来自运行时字段 `y0`。任务数据按需加载；需要该部分时，应先在客户端手动打开对应 NPC。

脚本只读当前官方进程的 ART 堆，不注入、不修改游戏。

原始 DEX/Smali 证明，`10503` 响应的 `1024` 数据标志块解压并解析 `com.hz.a.f[]`，再保存到 `com.hz.g.i.L0`。`com.hz.a.f` 包含 NPC ID、模型、名称、格坐标、主对话和各类交互参数。因此，NPC 数据不属于地图布局 JSON；也不能把首次完整列表归到 `10519`。

`10519` 是对编号 `1..13` 的 NPC 条目按需补取：请求体为数量和若干 `byte` 编号，响应返回可再次解析的 `com.hz.a.f[]`。是否实际发出取决于地图类型和条目状态。本次 2026-09-06 世界村重新进图与逐个对话抓包未出现 `10519`，完整列表来自 `10503`。

已验收样本 `captures/android-protocol/session-20260906-054106/` 同时保存原始 `traffic.pcap`、外层帧索引 `frames.jsonl` 和只读运行时导出 `npc-runtime.json`。PCAP 消息体仍受 SafeComm 保护；台词以运行时对象导出为实测证据。

## 分析顺序与范围

1. 以同一操作的运行时明文为语义基线。
2. 在原始 DEX/Smali 中核对发送构造和接收分支，补齐字段类型、顺序、可选位和错误分支。
3. 样本未覆盖的内容标记为“推断”；动态确认后再改为“实测”。
4. 优先覆盖登录、角色、地图、任务、战斗和背包。聊天、好友聊天、公会聊天等纯社交协议不属于离线版必需范围。
