# 微信小游戏忽略协议列表

本文记录对 Android 恢复版离线单机玩法没有实现价值的微信小游戏协议。采集器仍保存完整原始会话；筛选、分析和离线适配时跳过本表消息。

不要因为一次响应为空、与旧样本重复或字段尚未解析，就把玩法协议加入本表。只有协议职责已经确认，并且确认不属于离线单机范围时才追加。

## 维护规则

- 按消息号记录。请求和同号响应合并为一项；异号响应单独记录。
- 新增项必须写明忽略原因和证据。仅凭协议名不能判定。
- 后续若发现消息参与角色、地图、任务、战斗、背包或伙伴状态，应从本表移除并迁入[已采集的有用协议列表](miniapp-protocol-useful-list.md)。
- 原始 `.bin`、`timeline.jsonl` 和 `summary.json` 不删除，继续作为运行时证据。
