# 微信版接口与地图资源分析

日期：2026-09-05。此次只分析本地代码，没有执行游戏脚本、请求线上接口或下载 CDN 资源。已有《逆向分析.md》作为线索，以下结论已对照实现核查。

## 最有价值的发现

微信版将地图静态资源放在 CDN。场景加载代码按地图 ID 加载 JSON 和合并图集；进入地图的网络响应提供地图名称等信息，没有 APK 对应分支中的布局字节数组。因此，可以优先调查资源版本清单，不必先依赖低等级角色逐张进入地图。线上是否允许直接下载、清单是否覆盖全部地图，仍未验证。

这也说明两版协议不能仅凭编号一致就混用。微信版地图 ID 的当前场景字段读 int，原始地图 ID 可能额外读 short；10503 请求仍写 short。响应布局与 APK 有区别。

## HTTP 与资源入口

| 入口 | 作用 | 本地证据 |
| --- | --- | --- |
| `https://sjh5loginnew.good321.net/version` | GET 参数 `code_version`、`platform`；响应含 `version`、`host`、`port`、`cdnUrl` | `main.js:4242`；GET 包装 `main.js:584` |
| `v/{targetPf或WEB}/{res_version}.json` | CDN 资源版本清单；读取 `cfg`、`url`、`res` | `subpackages/main/main.min.js:100462` |
| `assets/map/{地图ID}.json` | 地图配置逻辑路径 | 同文件 `25269`、`169300` |
| `assets/map_merged/{地图ID}` | 合并图集逻辑前缀；加载器追加 PNG 和 JSON 后缀 | 同文件 `25275`、`46632`、`169307` |
| `assets/map_slice/{切片ID}.png` | 地图切片逻辑路径 | 同文件 `25278`、`73716` |
| `assets/map/{地图ID}/{地图ID}.jpg` | 地图模糊预览路径；定义存在，不代表当前场景加载必用 | 同文件 `25272` |
| `assets/sprite/model/{ID}.json`、`assets/sprite/fragment/{ID}` | 动画模型及片段逻辑路径 | 同文件 `25281` |
| `/wxbill`、`/submitOrder` | 计费、订单相关，非地图下载入口；未调用 | `main.js:4397`、`4268` |

上表的 `assets/...` 是逻辑路径，不能直接假定拼接 CDN 就能下载。`getRealUrl`（46529）查询版本清单的嵌套 `url` 字典，将路径转换为 `assets/{哈希前两位}/{哈希}{扩展名}`，其中前缀 `ad` 特殊替换为 `dirad`；地图目录还存在单独的回退替换逻辑。缺少映射可能返回 null。应先解析真实清单，再列出资源，避免猜测 ID 范围。

## 游戏消息索引

新生成 `api-cg-index.csv`：628 条具名 CG 常量，带定义行和全部文本引用行。它补充已有 `protocol-enums.csv` 的 Protobuf 枚举。常量存在不等于当前版本正在使用，也不代表 HTTP API；引用行包含定义本身，不能直接当调用次数。

| 编号 | 名称 | 用途 |
| --- | --- | --- |
| 10001 | CG_LOGIN_ACTORLIST | 角色列表 |
| 10501 | CG_SCENE_ENTERMAP | 进入地图 |
| 10502 | CG_SCENE_LEAVEMAP | 离开地图 |
| 10503 | CG_SCENE_WORLDDATA | 当前场景数据 |
| 10504 | CG_SCENE_PLAYER_MOVING | 移动 |
| 10506 | CG_SCENE_GO_MAP | 切换地图 |
| 10519 | CG_SCENE_GETNPC | NPC 数据 |
| 10520 | CG_SCENE_GETSPR | SPR 资源 |
| 10536 | CG_SCENE_GET_IMAGE_RESOURCE | 图片资源 |

10503 的构造函数 `createWorldDataMessage`（21548）依次写：当前地图 short、boolean、调用方传入的 int、两个零 byte，然后 `Service.sendProto`。这支持 APK 中该编号的解释，但不能证明可请求未解锁地图。

`Message`（23025）通过注册表选择 Protobuf 或 Egret ByteArray。`Socket`（103792）使用二进制 WebSocket。WebSocket 负载外层帧及登录会话仍需沿 Service 核查；本次没有验证可直接重放。APK 使用 TCP/SafeComm，不能直接把微信版消息送进 APK 连接。

地图响应 `processDataBlockFlagMsg`（20764）的 DATA_MAP_NORMAL / DATA_MAP_MINI 分支只读取两个字符串及一个 byte；地图加载任务（169285）另行取得配置和图集。部分特殊地图跳过这一路径，所以即便取得普通地图清单，也不能立即声称覆盖全部场景。

## 下一步顺序

1. 核实启动平台参数，读取并本地保存 `/version` 响应。
2. 下载并保存对应资源版本 JSON，解析 `url` 中的地图条目，得到可核对的地图列表。
3. 先下载已知地图 31414 的配置和图集，验证结构及与 APK 地图的对应关系。
4. 单图验证通过后，按清单批量保存地图依赖，记录成功、缺失及特殊地图，再接入本地浏览器。

重建协议索引：在此目录运行 `python export-api-index.py`。脚本包含小型解析自检，并检查 10503 名称及常量重名；此次运行通过，导出 628 条。脚本只读取格式化代码，不执行目标 JavaScript。
