# 01 — 建立桌面端最小采集闭环

**What to build:** 建立 MiniTrace 的最小端到端采集闭环。用户可以选择并复用采集工作区，从候选进程中选择目标，启动一次采集，看到至少一条实时游戏协议帧，正常停止采集，并从历史列表重新打开该采集会话。本 Ticket 使用可控的假采集后端，同时确立 macOS 与 Windows 后端共同遵守的公开 Tauri 命令与事件契约。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 应用采用 Tauri 2、Rust、Svelte 5 和 Tailwind CSS 4，可在当前 macOS 开发环境从源码启动。
- [ ] 首次运行可以选择采集工作区，重新启动后默认复用该工作区。
- [ ] 假采集后端能够提供候选进程，并跑通开始、ready、原始观察、游戏协议帧、正常停止和最终摘要事件。
- [ ] 一次采集会话的原始字节、追加式时间线和可重建索引均写入采集工作区。
- [ ] 停止采集会等待 worker 正常结束和最终摘要，不把强杀作为正常停止路径。
- [ ] 历史列表能够找到刚完成的采集会话，并重新读取其基本信息和帧记录。
- [ ] 自动化验收从公开 Tauri 命令与事件边界驱动完整流程，不依赖内部组件状态或真实微信。
