# 05 — 保证长时间采集与会话可恢复

**What to build:** 让采集会话能够安全跨越长时间运行、承载进程重启和应用异常退出。一个连续用户操作仍对应一个采集会话，每次重新附加形成可追踪的采集分段；已有原始证据在失败后仍可浏览和重建索引。

**Blocked by:** 03 — 打通 macOS 真实明文持续采集；04 — 提供实时协议检查工作台

**Status:** ready-for-agent

- [ ] 承载进程消失后，应用发现并验证新候选，并以新采集分段继续原采集会话。
- [ ] 新候选无法唯一确认时暂停重新附加并要求用户选择，不能自动混入其他实例。
- [ ] 中断区间、PID 变化、附加失败和零帧状态在采集会话中清楚可见。
- [ ] 应用异常退出后保留已有文件，并将未正常结束的记录恢复为不完整会话。
- [ ] 删除 SQLite 索引后，可以从原始字节文件和追加式时间线重建历史查询。
- [ ] 剩余磁盘空间低于安全水位时持续警告，但不自动停止采集或删除历史会话。
- [ ] 历史列表可以打开采集会话所在目录；历史资料不会被自动清理。
