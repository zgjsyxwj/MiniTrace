# 04 — 提供实时协议检查工作台

**What to build:** 提供面向协议分析人员的实时检查工作台。采集期间可以确认流量持续到达，筛选近期记录，并查看选中记录的原始内容；界面窗口受控，但磁盘上的采集会话保留全部证据。

**Blocked by:** 03 — 打通 macOS 真实明文持续采集

**Status:** ready-for-agent

- [ ] 实时列表展示时间、方向、消息号、协议名称、长度和哈希。
- [ ] 支持按消息号、协议名称、请求、响应和未分类明文载荷筛选。
- [ ] 可以查看选中记录的原始字节内容，并定位其采集分段和原始文件。
- [ ] 用户冻结或滚动实时视图时，后台采集与磁盘写入保持运行。
- [ ] 实时视图只维护有限窗口；窗口淘汰不删除采集会话中的任何原始观察。
- [ ] 假采集后端的确定性事件序列覆盖筛选、冻结、窗口淘汰和停止后的历史读取。
