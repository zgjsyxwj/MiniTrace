# 02 — 完成 macOS 环境诊断与目标选择

**What to build:** 在 Apple Silicon macOS 上识别操作系统、微信版本、候选进程及关键模块，并让用户从合格候选中选择《世界 Online》运行链。未知微信版本只能进入兼容性诊断，不能产生正式采集会话或显示正在采集。

**Blocked by:** 01 — 建立桌面端最小采集闭环

**Status:** ready-for-agent

- [ ] 界面显示当前 macOS、CPU 架构和微信版本。
- [ ] 应用根据进程角色、已加载模块和微信版本列出候选进程，而不是简单选择首个 PID。
- [ ] 单一合格候选可以被选择；多个合格候选并存时必须由用户确认目标。
- [ ] 当前验证对象包含微信 4.1.13、`WeChatAppEx`、`WeApp` 和 `WeChatAppEx Framework`。
- [ ] 未知或不匹配环境只输出兼容性诊断，不建立采集会话。
- [ ] 诊断和选择流程通过假进程清单覆盖支持环境、未知版本、无候选和多候选场景。
